# Teleprompter

Teleprompter para celular (iPhone e Android): o roteiro rola no alto da tela, perto da lente, enquanto a câmera grava.

- Abra o link no Safari (iPhone) ou Chrome (Android) e use "Adicionar à Tela de Início".
- Os roteiros ficam salvos só no próprio celular.
- Toque no texto para pausar/continuar; arraste para voltar ou avançar.
